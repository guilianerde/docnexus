# DocNexus 产品说明

DocNexus 面向需要跨会话记住项目决策、约定和解释的编码智能体。当前版本以文本与 skills 维护知识，并通过 PGLite/Postgres＋pgvector 和本地 embedding 提供语义召回：知识与代码一起保存，智能体按需查找并阅读全文。

## 核心体验

- “记住这个决定”：提炼为草稿，审阅后保存当前知识并记录来源时间线。
- “我们为什么这样设计”：查找相关文件，读取当前知识与必要的历史来源，给出有引用的解释。
- “这个约定改了”：先读旧知识，合并新材料，替换已经失效的结论；更新需用户授权。
- “把仓库带到另一台机器”：Git 中的文本即可查找和阅读，关键词查找和全文读取立即可用，语义召回自动重建本地索引。
- “我手动改了文档”：检查差异，经授权采纳，保留原始来源并记录编辑。

## 已实现

项目工作区、六个 skills、草稿封存、文档保存和删除、关键词及名称查找、关键词/向量融合召回与一跳图谱上下文、完整文档与时间线读取、概念和文档目录、skills 链接和版本刷新、哈希校验、路径边界与诊断。

当前知识由智能体整理，CLI 保存全文；实体别名与显式事实的来源、生效、到期、替代和撤回由代码校验，正文的事实引用由 CLI 自动生成有效断言及来源，事实在 metadata 只定义一次；不自动判断自然语言矛盾或改写块外自由叙述。时间线记录保存时间、更新摘要与来源，不是完整正文版本库。

## 边界与验收

- 本地 CLI 默认使用零配置 PGLite，也可通过 `DOCNEXUS_DATABASE_URL` 连接 Postgres；统一 pgvector、文档/chunks 与关系投影，每份投影在同一事务内更新。普通更新复用未变向量，增量维护 HNSW。随包 BGE q8 ONNX embedding，不在 CLI 内生成答案。
- `search` 是不依赖模型的字面匹配；`recall` 默认以文档级 RRF 融合关键词和本地向量排名，并补充一跳图谱证据。`--mode vector` 保留原有向量模式；综合回答与来源判断由智能体完成。
- 默认查找当前知识，历史问题显式读取时间线。
- 写入和删除有明确授权；只读操作可以自主触发。
- 不自动捕获聊天、不监听文件，不迁移旧格式。
- 完整性检查能发现文本缺失、未采纳编辑和哈希变化；本机项目锁与持久化事务日志覆盖 CLI 文本操作、保存/删除恢复和草稿入库收据；不协调外部编辑器、Git 或其他机器。

显式事实引用、跨文档自动刷新、有效时间变化、预览封存及依赖视图恢复也属于当前范围。

发布验收覆盖：真实本地模型与安装包主流程、中英文及代码标识符查找、克隆后直接读取和语义索引重建、更新时间线、删除无残留、项目隔离、草稿篡改与路径越界拒绝。
